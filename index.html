FAQ

Jawaban cepat — semua diambil langsung dari nobody0x.com

What are the three modes?

Security Workspace for code and patches, Daily Chat for natural talk and voice, Security Planner for artifact-first planning with approval gate.

Can I attach files?

Yes — images, PDFs, and code files (.php, .js, .py, etc.) can be sent with your message in the chat input.

What does “Unfiltered AI” mean?

In Workspace mode, fewer soft refusals — more structure, code blocks, and file-specific answers.

Why Telegram verification?

Blocks throwaway accounts from draining credits while letting verified users generate freely.

Need Pro before topup?

No. Topup credits work independently with the same verification rules.

Minimum topup?

Pakasir follows local packages. Crypto minimum is currently USD 8.33.

What are tokens used for?

Each chat message and streamed response in the cloud workspace — across all three modes.

Tokens run out?

Request blocked before execution. Top up or start Pro, then continue in the same workspace.

Privacy Policy

How DSOC AI handles account data, verification data, billing records, workspace usage, and support requests.

01

Information We Collect

We collect only what’s needed to operate the workspace and keep limits accurate.

  • Account identity: email, display name, login provider, password hash
  • Telegram verification: chat ID, verified email, time, anti-abuse status
  • Billing records: payment method, order IDs, token batches, Pro status
  • Workspace usage: model requests, token consumption, errors, audit events
02

How We Use Data

To provide the product, enforce limits, and help with recovery.

  • Authenticate & tie one Telegram identity to one email
  • Apply token limits, Pro entitlement, topup credits & reconciliation
  • Debug failed requests, quota issues, webhook events
  • Respond to support / legal / security requests
03

Data Protection

Server-side controls and protected configs to reduce exposure.

  • Payment & API secrets stored server-side, not exposed to browser
  • Passwords stored as hashes, not plain text
  • AI usage can be gated until Telegram verification passes
  • Don’t paste passwords / private keys / seed phrases into prompts
04

Retention And Requests

Operational records may be retained while account exists or for billing/abuse/legal.

  • Request review / correction / deletion via contact page
  • Some billing / anti-abuse / security records may be retained as required
